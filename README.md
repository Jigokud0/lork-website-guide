# Сайт с ИИ: от задачи до запуска

Открытый русскоязычный информационный гид по созданию сайта с ИИ на примере Lork.
Подготовлен для проекта Lork; не является независимым обзором.

Публичный сайт: https://jigokud0.github.io/lork-website-guide/

## Что внутри

- Выбор формата сайта и подготовка материалов.
- Скачиваемый бриф и явно вымышленный пример задания.
- Сценарии отраслевых шаблонов, кейс PRAVDA и проверка перед запуском.
- Обычные HTML-ссылки на первичные страницы Lork с referral UTM.

## Устройство

Статические HTML/CSS, без сборки, сторонних шрифтов, аналитических скриптов,
форм, сбора персональных данных, платежей и SaaS-функциональности.
GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает Jekyll.

Исходящие ссылки не содержат `nofollow`, `ugc` или `sponsored`.
Это не гарантирует индексацию, SEO-вес ссылок или рост позиций.

UTM: `github_pages / referral / website_guide`; `utm_content` обозначает блок.
Фактические переходы и последующие регистрации проверяются на стороне Lork.
Этот репозиторий не получает доступ к аналитике или пользовательским данным.

## Редактирование

Откройте `index.html` и `styles.css`. Для локального просмотра достаточно
любого статического HTTP-сервера. При изменении адреса обновите canonical,
Open Graph URL, sitemap и README. Перед публикацией проверьте мобильный экран,
ссылки и скачивание `brief.md`.
